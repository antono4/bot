# Agent OS - AI Agent dengan Web Interface

Agent AI dengan interface web berbasis HTML/JS.

## Fitur

- Web Interface Modern
- AI Chat dengan streaming
- Multi-agent support
- File browser
- Code editor
- Terminal emulator

## Quick Start

1. Buka index.html di browser
2. Masukkan API key
3. Mulai chat!

## Requirements

- Browser modern (Chrome, Firefox, Edge)
- OpenAI API key
