|-----|--------|----------|
| 🤖 Trading | `bot-trading/` | Cryptocurrency & stock trading automation |

## 🚀 Quick Start

```bash
# Clone repository
git clone https://github.com/antono4/bot.git
cd bot

# Pilih bot yang ingin digunakan
cd bot-trading

# Install dependencies
pip install -r requirements.txt

# Copy environment file
cp .env.example .env
# Edit .env dengan credentials Anda

# Run bot
python main.py
```
